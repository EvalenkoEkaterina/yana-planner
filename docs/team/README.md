## Общее основание

- Сценарий `examples/r03.json`, срок приёмки 328 ч, возврат 492 ч.
- A1/A2/A3 уже реализованы по отдельности. Повторно создавать их по старому ТЗ не нужно.
- `experiments.py` уже формирует сводку, `sensitivity.py` - экономическую чувствительность.
- До запуска фиксируются входы, сроки и лимиты. Новая информация раскрывается обоим методам одновременно.
- SIM-A/B и расходы остаются сценарными; неизвестные фактические параметры не заменяются нулями.

## Совместная работа

Одна задача - отдельная ветка и Pull Request с описанием изменений, командой повторения и проверками. Общие модули и CLI согласуются перед объединением. Формат сценария сохраняется единым.

Каждая участница лично повторяет свой запуск и объясняет входы, результат и ограничения. Новый модуль не должен повторять существующую реализацию.

# Маленькая погодная модель Яны

Рабочий эксперимент: три обучаемые медианные поправки к внешнему прогнозу ECMWF IFS 0.25 (ветер, температура, осадки). Это коррекция готового прогноза, а не самостоятельный прогноз погоды с нуля. Нынешние погодные ограничения и сайт не изменяются.

Всего 480 строк: две точки (Нижнеянск и Усть-Куйга), 1–5 июля 2024 и 2025 годов. 240 строк 2024 года обучают поправки, 240 строк 2025 года используются только для оценки. Данные взяты из уже скачанного архива; источники, координаты, время скачивания и контрольные суммы полных исходных ответов сохранены в data.json. Время UTC. Пропуски не заменяются нулями. Эталон — ERA5, не независимые наблюдения. Точное время выпуска не установлено, forecast_issued_at=null. 2025 год уже рассматривался ранее: оценка не является новым слепым тестом.

Из корня проекта с установленными зависимостями:

```sh
PYTHONPATH=src python scripts/train_small_forecast.py
PYTHONPATH=src python scripts/predict_forecast.py models/forecast_small/model.json examples/forecast_small/input.json outputs/small_prediction.json
```

Обучение полностью офлайн, без 70 тысяч строк и без новых библиотек. Сохранённая модель уже готова к запуску; переобучать её перед прогнозом не нужно. Для новых входов используется существующий контракт predict_forecast.py: семь показателей внешнего прогноза с единицами, координатами и временем. Реанализ в прогнозный вход не передаётся.

Ограничения: всего пять июльских дней и две точки; перенос на другие сезоны/маршруты не проверен. Малый объём выбран для простоты, а не как доказательство достаточности. Сравнение с исходным прогнозом находится в models/forecast_small/metrics.json; ухудшения не скрываются. Модель экспериментальная и не управляет запретами движения автоматически.

Полученная оценка MAE на 240 строках 2025 года:

| Показатель | Исходный прогноз | С поправкой |
|---|---:|---:|
| Ветер, м/с | 1.30975 | 1.617875 |
| Температура, °C | 1.923333 | 0.89 |
| Осадки, мм | 0.033333 | 0.033333 |

Температура улучшилась на этой малой выборке, ветер ухудшился, осадки не изменились. Это не подтверждает преимущество модели в целом. Коэффициенты после просмотра оценки не подбирались.

# Документация Yana Planner

Материалы разделены по назначению. Все команды выполняются из корня репозитория, независимо от расположения инструкции.

| Папка | Назначение | Основные материалы |
|---|---|---|
| `model/` | Сущности, поток данных, оптимизация | [Архитектура](model/architecture.md), [формулы](model/formulation.md) |
| `data/` | Источники, факты, допущения | [Происхождение данных](data/provenance.md) |
| `guides/` | Установка и запуск | [Команды](guides/commands.md), [первый эксперимент](guides/first-experiment.md) |
| `experiments/` | Условия опытов и результаты | [Каталог](experiments/README.md) |
| `quality/` | Проверки и воспроизводимость | [Проверка проекта](quality/checks.md), [ресурсы](quality/resource-controls.md) |
| `team/` | Ответственность и актуальные задачи | [Команда](team/README.md), [задача интегратора](team/tasks/integration-demo.md) |
| `specs/` | Исходное ТЗ и статус требований | [Сопоставление с кодом](specs/README.md) |
| `archive/` | Прошлые планы, проверки и интеграции | [Архив](archive/README.md) |

**Для защиты:** архитектура → происхождение данных → эксперименты → ограничения модели.

**Для разработки:** команды → архитектура → актуальная задача → проверки → [совместная работа](../CONTRIBUTING.md).

Исходное ТЗ описывало более старую версию. Перед выбором задачи сверяйтесь с его актуальным статусом. Сценарные данные и ограничения не меняют статус от переноса документации.

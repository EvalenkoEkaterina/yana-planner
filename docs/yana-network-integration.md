# Сеть Яны: подключение справочника

Источник команды — архив `yana-network-for-lead.zip`. Оригинальные JSON и описание
сохранены в `data/network/`. Адаптер `network_import.import_yana_network` создаёт
контракт `yana-river/1`; его результат — `static/data/river-network.yana.json`.
Адаптер не меняет исходный словарь и не выводит времена/тоннаж из километров.

## Что работает

На главной странице: «Выбрать пункты речной сети» → «Яна · справочные расстояния».
По умолчанию Нижнеянск → Северный → Усть-Куйга, 324 км. Усть-Куйга → Батагай —
383 км, весь коридор — 707 км. Источники и строки документа видны у каждого участка.
В исходном плане АТ-442-р, PDF-страница 75, строки 1397–1400 сверены 13.11.2026.
Это справочник исходного плана, не сводная актуальная редакция и не допуск судна.

Граф — цепочка: он собирает путь и расстояние, не выбирает между реальными
альтернативами. Тестовая вымышленная сеть остаётся отдельным переключателем.

Три населённых пункта доступны как кандидаты для отправления/назначения только
для учебного расчёта. Для них не подтверждены причалы и операционные возможности.
Северный и устье Адычи — `waypoint_only`: видны в пути, но отключены в выборе
получателя/отправителя. Сервер импорта пакета также отклоняет их как терминалы.
Общий поиск пути может находить их как точки сети — это не разрешение на погрузку.

Топология двусторонняя: физическое соединение можно просматривать в обоих
направлениях. Из этого не следуют одинаковое время движения или разрешение прохода.

При переносе маршрута пользователь подтверждает учебные условия. Тарифы, события
и общий календарь закрытий сбрасываются. Времена задаются отдельно. Снимок сети,
путь и источники сохраняются вместе с расчётом; ядро READY/MILP не изменено.

|---|---|---|
| nizhneyansk | nizhneyansk | Только соответствие идентификаторов |
| ust-kuyga | ust_kuyga | Только соответствие идентификаторов |

| adycha-mouth | null | Координаты неизвестны |

У всех записей `automatic_use=false`. Это не покрытие всего участка и не подключённая
прогнозная модель. При выборе нового маршрута прежнее погодное событие не переносится.
Для активации нужна проверка координат/CRS, пространственного покрытия участка,
дат/времени выпуска прогноза и наличия всех требуемых часов.

## Координаты: что проверено и чего не хватает

Сохранены исходные значения, тексты градусов/минут и статусы из архива. Шесть
десятичных знаков не объявляются точностью измерения. Данные — ориентиры поселений,
не причалов. Автопривязка к погоде заблокирована независимо от наличия числа.

13.11.2026 повторно запрошен оригинальный PDF Роскадастра: прямое получение не
прошло проверку цепочки сертификатов; резервный веб-инструмент завершился тайм-аутом.
Оригинал и CRS независимо не подтверждены. Защита соединения не отключалась.
Числа не исправлялись догадками и не объявлены проверенными. Нужны доступный оригинал
с системой координат или другой проверенный координатный источник.

## Проверка

Автотесты: все 20 направленных пар связаны; суммы 324/383/707 совпадают; неизвестные
операционные параметры остаются null; неправильные источники/расстояния отклоняются;
промежуточные узлы не принимаются как терминалы; явные погодные алиасы не разрешают
автоприменение. Малый расчёт проверяет сохранение реальной географии при неизменных
ручных транспортных параметрах. Старые примеры и вымышленная сеть также проверяются.

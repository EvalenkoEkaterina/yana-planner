# Пошаговый выбор флота и рейсов

Открыть главную страницу. Одновременно показывается один этап; кнопки сверху и «Назад / Далее» переключают разделы, сохраняя поля в памяти страницы.

1. **Направление** — выбрать маршрут, готовый пример, речную сеть или пакет условий.
2. **Задание** — тоннаж, срок приёмки, начальный запас, хранилище, срок возвращения и лимит поиска.
3. **Суда** — состав флота, вместимости, доступность, длительности, скорость погрузки и ставки каждого судна.
4. **Поступления** — время и тоннаж партий в пункте отправления.
5. **Экономика** — стратегия выбора плана, схема оплаты и подтверждения. Тарифы редактируются в карточках судов; ссылка переводит на нужный этап.
6. **Ограничения** — задержка топлива, погодное событие и область применения модели.
7. **Запуск** — сводка задания, экспорт условий и расчёт READY/MILP.

Все прежние поля остаются внутри исходной формы. Переключение этапа не меняет условия и не запускает расчёт. Неверное обязательное поле открывает соответствующий этап. Обновление страницы или переход по готовому примеру загружает условия заново; для сохранения правок скачайте пакет условий.

Проверено в браузере: отображение одного этапа, сохранение тоннажа после переключений, отдельные поступления, переход к ошибочному полю из запуска и настоящий расчёт 400 т с переходом в сохранённый отчёт. Расчётное ядро не изменялось.

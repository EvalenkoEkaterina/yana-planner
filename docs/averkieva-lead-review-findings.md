# Проверка пакета Аверкиевой

13.11.2026. Архив averkieva-lead-review.zip проверен в изолированной копии
на базе f1b0228. Рабочие файлы основной инженерной ветки не заменены.
Исходный архив сохранён без изменений.

## Проверки

- 203 Python-теста прошли с файлами архива поверх актуального ядра.
- 6 JS-тестов импорта прошли.
- Ruff проверка кода прошла.
- GET / с новыми шаблонами возвращает 200.
- Дополнительные проверки воспроизвели две ошибки, не покрытые тестами архива.

## Исправить до подключения формы

1. dispatcher.js, gather(): при пустой скорости в объект судна всё равно
   попадает load_setup_h=0 из формы. Актуальный Scenario отвергает это поле
   без load_rate_tph. Воспроизведение: в исходный пакет Батагая добавить
   load_setup_h=0 каждому судну и вызвать import_route_package — InputError.
   Решение: передавать load_setup_h только для скоростной модели погрузки;
   ненулевую подготовку без скорости явно отклонять. При скоростной модели
   не передавать пустой load_h как null.

2. route_import.py: Scenario.from_dict сортирует arrivals, но arrival_index
   события остаётся индексом исходного порядка. Воспроизведение:
   arrivals=[{h:120,t:100},{h:0,t:500}], событие index=0, объявление=60,
   перенос=168. Импорт проходит; затем apply_event получает индекс партии
   в 0 ч и отклоняет её как уже произошедшую. В другом порядке возможна
   задержка другой будущей партии. Решение: сортировать с сохранением
   исходных индексов и переназначать event.arrival_index; добавить регрессию.

## Отдельная задача интегратора

Архив специально не подключает route_package_json к серверу. capabilities
пусты, новые режимы заблокированы до серверного подключения. Это заявленное
состояние поставки, не скрытая реализация. Нельзя просто включить флаги:
старый POST / проигнорирует envelope и может рассчитать прежний сценарий.

В инженерной ветке уже есть POST /api/plan. Нужно выбрать один серверный
адаптер envelope → scenario/deadline/strategy/cost_terms/event, сохранить
route/sources/facts в снимке и восстановить полный пакет после ошибки.
Погодный конвертер для этого не требуется: пока передавать явное событие.

После исправления: проверить в браузере обычный R03, второй маршрут,
денежный пример, серверную ошибку с восстановлением полей, историю и отчёт.
Браузерный сквозной запуск нового маршрута в рамках этой проверки не проведён:
серверная интеграция ещё не выполнена. Наличие 203 проходящих тестов
не означает готовность этой формы к запуску всех новых параметров.

## Данные

Батагайский пример корректно обозначен как учебный: 600 т, параметры флота,
длительности и тарифы сценарные. Подтверждённая география не превращает
расписание в фактическую перевозку. Новые найденные первичные заявки и
эксплуатационные наблюдения находятся в data/research; они пока частичные.
Публикации и географические источники архива требуют отдельной проверки
перед обозначением нового профиля как полностью основанного на реальных данных.

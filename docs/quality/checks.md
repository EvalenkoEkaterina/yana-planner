# Проверки и воспроизводимость

## Проверка изменений

После установки основного окружения из корня репозитория:

```sh
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
ruff check src tests
ruff format --check src tests
```

Окружение должно удовлетворять [pyproject.toml](../../pyproject.toml). Excel-зависимости устанавливаются через [requirements.txt](../../requirements.txt). Графики требуют необязательного дополнения `.[plots]`.

При реорганизации документации 12 ноября повторно пройдены все 170 тестов; Ruff check и format --check также пройдены. Расчётное ядро соответствует версии `58c0ba5`: 148 прежних тестов и 22 проверки ограничения партии. [Содержание проверок A3](../experiments/payload-restriction.md#проверка). Число тестов не является доказательством достоверности операционных предпосылок или реальной эффективности.

## Проверка демонстрации

1. Запустить `plan` или `replan` по [инструкции](../guides/commands.md).
2. Сверить `results.json`, HTML и сводку. Для сравнения принимать показатели независимого валидатора.
3. Зафиксировать версию кода, входы, сроки, лимиты ступеней и использование `reference`.
4. Смотреть статусы каждой ступени MILP. Допустимый план не обязательно доказанно оптимален.
5. При конфликте ожидаем `requires_intervention` и неизвестный итог, а не нулевую доставку. CLI возвращает код 2 для предусмотренного конфликтного опыта.

## Документация

При переносе файлов обновлять относительные ссылки во всех затронутых документах. Исторические протоколы сохранять в архиве с датой и пометкой статуса. В инструкциях отделять готовые команды от предлагаемых интерфейсов будущих задач.

Локальные результаты складывать в `outputs/`, которое исключено из Git. Для публикации выбирать согласованный комплект и одну версию расчёта. Контроль ресурсов: [инструкция](resource-controls.md).

При переносе также проверены относительные ссылки README, CONTRIBUTING и всей документации; отсутствующих локальных целей не найдено. Исходное ТЗ сохранено побайтно. Внешние источники в рамках этой задачи повторно не проверялись.

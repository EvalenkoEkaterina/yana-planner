# Происхождение и статусы данных

Проект опирается на согласованные сценарии v2 от 9 ноября 2026 года. Фактическое исполнение заказа на 1650 т не восстановлено. Входы и результаты не являются журналом реальной навигации.

| Сведения | Статус |
|---|---|
| НКТ и ориентир 1650 т | Опубликованные плановые требования закупки 32615967884 |
| Поступления 0/120 ч, 825+825 т | Сценарные допущения R03 |
| Суда SIM-A/B, доступность, полезная партия, времена | Сценарные допущения, не конкретный реальный флот |
| Приёмная ёмкость, отбор, один причал каждого типа | Сценарные условия |
| Перенос 120→168 ч, сообщение в 60 ч | Новый сценарный эксперимент |
| Исторические рейсы СПН-703 | Подтверждение работы с НКТ, не доступность на нужные даты |
| Реальная осадка/грузовая шкала/поступления | Не подтверждены, не заполнены нулями |
| Переменные расходы | Неизвестны; шаблон оставлен пустым |

# Обучаемая коррекция погодных прогнозов

Результат первого эксперимента: обучены собственные модели коррекции ветра,
температуры и осадков, но ни одна не прошла заранее заданный отбор для автоматического
применения. Рабочий model.json сохраняет внешний прогноз без коррекции.
Это отрицательный результат проверки, а не доказанная польза ML.

## Данные

70 272 строки «точка × час» за июнь–сентябрь 2024–2026:
Яна (Нижнеянск, Усть-Куйга), Лена (Тикси, Жиганск), Колыма (Черский,
Среднеколымск), Индигирка (Чокурдах, Белая Гора). Это отдельные точки у рек,
не покрытие всех участков водных путей. Координаты получены через Open-Meteo
Geocoding; сеточные координаты поставщиков сохранены в аудите.

Вход — ECMWF IFS 0.25, прогноз с фиксированным упреждением 24 часа через
[Previous Runs API](https://open-meteo.com/en/docs/previous-runs-api).
Целевые значения — [ERA5](https://open-meteo.com/en/docs/historical-weather-api).
Оба продукта принадлежат семейству ECMWF: проверка не независима от семейства
моделей и не заменяет сверку с метеостанциями. ERA5 — реанализ, не судовые измерения.
Атрибуция: Open-Meteo и ECMWF, CC BY 4.0.

Прогнозные признаки: ветер 10 м (м/с), температура 2 м (°C), осадки (мм за час),
влажность (%), давление на уровне моря (гПа), облачность (%), направление ветра (°).
Добавлены календарные/географические признаки и фиксированные взаимодействия.
Нет фактических будущих наблюдений среди признаков. Цели: ветер, температура, осадки.
Видимость, лёд, глубины, наводнения и безопасность рейса не прогнозируются.

Проверены единицы, совпадение UTC-часов, отсутствие дублей и пропусков. Каждая
из 48 выгрузок содержит 2928 часов. URL, время получения и SHA256 сохраняются;
при обучении контрольные суммы проверяются. Сырые 5.6 МБ находятся в игнорируемой
outputs/forecast/raw и не отправляются случайно в репозиторий.

## Разделение и метод

- Обучение: 2024, шесть точек Яны/Лены/Колымы, 17 568 строк.
- Выбор модели: 2025, те же точки, 17 568 строк.
- Тест времени: 2026, те же точки, 17 568 строк.
- Тест переноса: 2026, две точки Индигирки, 5856 строк.
- Индигирка 2024–2025: 11 712 строк исключены из обучения и подбора.

Между сезонными выборками большой временной разрыв. Случайное перемешивание часов
не используется. Нормировка рассчитана только на обучении. Выбор и коэффициенты
сохраняются до вычисления тестовых метрик. После просмотра теста параметры не менялись.
Этот тест теперь использован: следующая итерация потребует новой независимой проверки.

Кандидаты: внешний прогноз, обученная медианная поправка, ridge-регрессия остатка
с 24 признаками и alpha 1/100/10000. Коэффициенты обучаются NumPy; новых зависимостей
нет. Отрицательные прогнозы ветра и осадков ограничены нулём. Это небольшая обучаемая
статистическая модель, не собственная глобальная физическая модель атмосферы.

Отбор на 2025: MAE минимум на 1% лучше исходной; RMSE не хуже более чем на 5%;
MAE в специальных подвыборках не хуже более чем на 5%: ветер >=8 м/с, осадки
>=1 мм/ч, температура от -2 до +2 °C. Это критерии исследовательского отбора,
не эксплуатационные пороги. Победитель среди прошедших — по MAE. Иначе остаётся
исходный прогноз. Все кандидаты, в том числе отклонённые, сохранены.

## Результат

На валидации лучшая по общей MAE ridge-коррекция температуры уменьшила MAE
с 1.456 до 1.372 °C, но около 0 °C ухудшила её с 0.822 до 1.002 °C.
Для ветра улучшение общей MAE лучшего ridge-варианта меньше 0.1%, а ошибка при
ветре >=8 м/с выросла с 2.885 до 3.430 м/с. Осадки: все ridge-варианты ухудшили MAE,
хотя некоторые снизили RMSE. Нельзя выбирать одну удачную метрику и скрывать остальные.

В 2025 для отбора были всего 239 часов ветра >=8 м/с и 147 часов осадков >=1 мм/ч
по шести точкам; они не являются независимыми штормами. Большое общее число строк
не гарантирует достаточного числа редких событий. Средняя ошибка осадков особенно
зависит от преобладания сухих часов.

Итоговый режим без коррекции на тесте 2026:

| Проверка | Ветер MAE, м/с | Температура MAE, °C | Осадки MAE, мм/ч |
|---|---:|---:|---:|
| Яна, Лена, Колыма | 1.008 | 1.360 | 0.0534 |
| Индигирка, не виденная при обучении | 1.150 | 1.217 | 0.0430 |

Это качество исходного IFS относительно ERA5, не выигрыш нашей модели.
metrics.json содержит разбивку по точкам, RMSE, смещение и ошибки превышений.
Парный bootstrap использует недельные блоки и переносит все точки одной недели
вместе; у выбранного raw-режима разница с baseline тождественно нулевая.
Доверительные интервалы не означают проверку на всех российских реках.

## Воспроизведение

```sh
source .venv/bin/activate
python scripts/fetch_forecast_training.py
PYTHONPATH=src python scripts/train_forecast.py
PYTHONPATH=src python scripts/predict_forecast.py outputs/forecast/model.json outputs/forecast/example_input.json outputs/forecast/example_prediction.json
```

Файлы outputs/forecast: manifest.json, selection.json, trained_candidates.json,
model.json, metrics.json, example_input.json и example_prediction.json.
trained_candidates.json содержит реальные обученные коэффициенты; model.json —
составной выбранный режим с явным fallback. В результате inference поле
correction_applied показывает применение коррекции для каждого показателя.
Пример входа не содержит реанализа. Для новых маршрутов требуются новые проверки;
для других сезонов, моделей и горизонтов inference отклоняется.

## Что нужно для следующего улучшения

Независимые измерения метеостанций, больше независимых эпизодов сильного ветра и
осадков, информация о сменах исходной прогнозной модели и новый закрытый тест.
Можно исследовать локальную/сезонную калибровку, вероятности превышений и нелинейные
методы. Они не должны подбираться по уже просмотренному итоговому тесту 2026.
Для прогноза задержек дополнительно нужны фактические рейсы и причины задержек.
Погодные прогнозы сами по себе не обучают безопасной загрузке или допустимости рейса.

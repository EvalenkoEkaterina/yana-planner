# Погодный контракт для графа

Запуск из корня с установленными зависимостями:

```sh
PYTHONPATH=src python scripts/weather_feed_demo.py
```

Вход: examples/weather_feed/input.json (240 точка-часов, две реальные точки Яны, 1–5 июля 2025). Единый выход: outputs/weather_feed/values.json. Один готовый объект: examples/weather_feed/output_example.json. В каждом объекте есть точка и координаты, начало/конец с UTC, показатель/единицы, источник, скачивание/выпуск, тип данных, correction_applied и missing. По умолчанию исходный ECMWF IFS; маленькая коррекция остаётся отдельным экспериментом и не допускается к ограничениям.

Правило отдельно: examples/weather_feed/rule.json. Результат: outputs/weather_feed/restrictions.json; эталон — examples/weather_feed/expected_restrictions.json. При сценарном пороге 8 м/с превышений нет, closures=[]. Это проверенное отсутствие превышений, не отсутствие данных. Любой пропущенный час или выбранная точка дают insufficient_weather_data, «Недостаточно погодных данных», closures=null. Синтетический тест отдельно проверяет объединение соседних часов; реальные значения не изменяются.

Привязка: examples/weather_feed/segment_mapping.json. segments — словарь «реальный ID участка → объект с point_ids, status, method, limitations». Сейчас словарь пуст: реальные ID должен сообщить владелец графа. Предложение по двум точкам лежит в pending с segment_id=null. mapped_points принимает только явно согласованные записи status=confirmed. Тестовые причалы к погоде не привязаны.

Ограничения: координаты — запрошенные точки, а погода сеточная. Две точки не покрывают всю реку. Максимум выбранных точек применяется ко всему маршруту как явное упрощение, без учёта времени прохождения участка. Это исторический фрагмент прогноза, не текущий прогноз и не реанализ. Время выпуска неизвестно: null; скачивание не заменяет выпуск. Режим historical_demo разрешает только условный опыт и маркирует доступность unverified. Режим as_of_decision требует известные времена выпуска и скачивания не позже решения, иначе блокирует ограничения. Наличие метаданных само по себе не гарантирует качество прогноза. Часовая длительность действия — допущение интеграции. Уверенность не оценена. Общий оптимизатор, граф и текущий сайт не изменены.

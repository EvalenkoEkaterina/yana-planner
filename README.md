# Yana Planner

Планирование доставки нефтяного котельного топлива Нижнеянск - Усть-Куйга. Команда «Трикс», кейс МАИ 3.

Система выбирает судно, время погрузки и партию, проверяет расписание и перестраивает будущие рейсы при изменении условий. Сравниваются правило READY и целочисленная оптимизация MILP на SciPy/HiGHS.

**Статус:** сценарный прототип. Ориентир 1 650 т взят из закупочной документации; суда SIM-A/B, поступления, длительности и возможности приёмки заданы сценарно. Результаты не подтверждают безопасность реального рейса или фактическую экономию перевозчика.

## Быстрый запуск

Python 3.12+. Выполнять из каталога этой версии репозитория.

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pip install --no-deps -e .
yana plan examples/r03.json --deadline 328 --reference examples/r03.reference.json --out outputs/static
```

В Windows активация: `.venv\Scripts\activate`.

Откройте `outputs/static/report.html`. Рядом сохраняются JSON, CSV и журнал баланса. `--reference` передаёт ранее найденный план как кандидата и заново проверяет его. Для поиска с нуля уберите флаг; при лимите времени найденный план может отличаться.

## Что реализовано

- Входы JSON и импорт двух поддерживаемых макетов Excel с листом `Входы_модели`.
- Поступления, доступность судов, полный оборот, причалы, ограничения движения и динамическая ёмкость приёмки.
- Приоритеты MILP: объём к сроку, число рейсов, последняя приёмка.
- Три типа обновления: задержка топлива, недоступность судна, ограничение партии. Одно сообщение за запуск.
- Сохранение начатых рейсов и диагностика конфликтов для диспетчера.
- Независимая проверка, отчёты, серия сроков и сценарная экономическая чувствительность.

Прогноз погоды, перевод уровня воды в загрузку и последовательность событий пока не реализованы. Подробности - в [статусе ТЗ](docs/specs/README.md).

## Проверенные примеры

R03, срок приёмки 328 ч. Числа относятся к сохранённым проверенным запускам с известным MILP-кандидатом.

| Условия | READY: принято / рейсы / последняя приёмка | MILP: принято / рейсы / последняя приёмка |
|---|---|---|
| Исходные | 1 650 т / 6 / 276 ч | 1 650 т / 5 / 224 ч |
| Ограничение партии A3 | 1 650 т / 6 / 276 ч | 1 650 т / 5 / 232 ч |

Это не преимущество по всем показателям. [Все точки A3, компромиссы и статусы поиска](docs/experiments/payload-restriction.md).
